# 📊 Product Data Cleaning & Analysis

## 📌 Project Overview

This project focuses on **cleaning and preparing a product dataset using Microsoft Excel**.

The dataset contains information such as:

* Product ID
* Product Name
* Brand Name
* Price
* Quantity
* Category

The main objective was to identify and fix data-quality issues and prepare the dataset for further analysis.

---

## 🧹 Data Cleaning Performed

### 1. Handling Missing Values

* Identified missing values in the **Price** column.
* Identified missing values in the **Category** column.
* Categories were assigned based on the corresponding product type.
* Missing prices were handled using similar-product values where appropriate.

### 2. Correcting Inconsistent Data

* Standardized inconsistent capitalization in **Product Name**.
* Corrected the category typo:

`Electroni` → `Electronics`

### 3. Removing Duplicate Records

Duplicate rows were identified based on all columns and removed using Excel's **Remove Duplicates** feature.

### 4. Data Transformation

* Split **Product ID** into:

  * Manufacturing Date
  * Country Code
* Combined **Brand Name** and **Product Name** into a new **Product Brand** column.

### 5. Number Formatting

* Formatted **Price** values as currency.
* Applied appropriate date formatting to the Manufacturing Date where the year information was available.

### 6. Conditional Formatting

* Applied **Data Bars** to the Price column to visualize price differences.
* Highlighted **Electronics** products using conditional formatting.
